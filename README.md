## Research interest

I am interested in how a model learns from labelled examples to recognise vehicles in new images, and how reliably it works under changes in lighting, camera distance, appearance, and partial occlusion.

The initial proposal is a fixed-camera road-traffic monitoring prototype that combines vehicle detection, classification, tracking, and counting. Evaluation would examine both monitoring accuracy and processing speed.

## Current status

This repository contains the thesis application proposal. The exact transportation scenario, target categories, dataset, and final scope will be agreed with the supervisor.

The proposed workflow starts with a pretrained detector. Fine-tuning would be investigated if representative labelled data and computing resources are available.
